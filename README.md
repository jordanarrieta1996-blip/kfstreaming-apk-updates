Las versiones oficiales de KFStreaming se publicarán aquí cuando la firma permanente y el sistema de actualización estén configurados:

**[Consultar versiones disponibles](https://github.com/jordanarrieta1996-blip/kfstreaming-apk-updates/releases)**

## Actualizaciones desde la aplicación

La APK podrá comprobar una versión publicada en `latest.json`, descargarla de forma segura y solicitar permiso a Android para instalarla. La instalación requiere autorización del usuario.

Cada lanzamiento incluirá:

- `kfstreaming.apk` — APK firmada, en una GitHub Release pública.
- `latest.json` — número de versión, descarga, notas y SHA-256 para verificar el APK.

Solo se distribuirán esos archivos. **Aquí no se publicará código fuente, credenciales ni claves de firma.**

Soporte y tienda: [kfstreaming.shop](https://kfstreaming.shop/).
